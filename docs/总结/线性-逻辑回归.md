## 逻辑回归的核心概念：从线性回归到分类决策

逻辑回归是一种广泛使用的分类算法，尤其在二分类问题中表现出色。本文将围绕逻辑回归与线性回归的关系、正例与负例的定义、决策边界的形成以及阈值选择的重要性，以浅显易懂的方式展开论述，并通过实例说明数学原理。这四个知识点紧密相连，共同构成了逻辑回归的工作机制：逻辑回归基于线性回归模型，通过非线性变换估计正例概率，进而利用决策边界进行分类，而阈值的选择则灵活调整决策边界以优化分类性能。

### 1. 逻辑回归与线性回归的渊源：从连续预测到概率估计

逻辑回归可以视为线性回归的自然延伸，两者都依赖于线性模型，但目标不同。线性回归用于连续值预测，其数学形式为：
$$
y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_n x_n
$$
其中，$y$ 是预测值，$\beta_i$ 是系数，$x_i$ 是特征。例如，用学习时间（小时）预测考试分数，线性回归可能输出如 $y = 50 + 5x$，表示每多学1小时，分数增加5分。

然而，在分类问题中，我们需要预测类别（如通过/不通过），而不是连续值。逻辑回归在线性回归的基础上，引入了sigmoid函数（也称为逻辑函数），将线性输出映射到0和1之间的概率值。sigmoid函数定义为：
$$
\sigma(z) = \frac{1}{1 + e^{-z}}
$$
其中，$z = \beta_0 + \beta_1 x_1 + \cdots + \beta_n x_n$ 是线性部分。逻辑回归模型输出正例的概率：
$$
P(y=1|x) = \sigma(z) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 x_1 + \cdots + \beta_n x_n)}}
$$
这里，$P(y=1|x)$ 表示在给定特征 $x$ 下，样本属于正例的概率。sigmoid函数具有S形曲线，当 $z$ 很大时，概率接近1；当 $z$ 很小时，概率接近0。这种变换使得逻辑回归能够处理分类问题，同时保留线性模型的简洁性。

**关联性**：逻辑回归的核心是线性模型，但通过sigmoid函数实现了从连续值到概率的转换，这为后续定义正例/负例和决策边界奠定了基础。

### 2. 逻辑回归的正例与负例：概率解释与分类基础

在二分类问题中，我们必须明确正例和负例。正例通常是关注的目标类别（如考试通过、疾病存在），标记为 $y=1$；负例则是相反类别（如考试不通过、健康），标记为 $y=0$。逻辑回归直接估计正例的概率 $P(y=1|x)$，而负例的概率为 $P(y=0|x) = 1 - P(y=1|x)$。

举例来说，假设我们用学习时间预测考试通过（正例）或不通过（负例）。给定学习时间 $x$（小时），逻辑回归模型输出 $P(y=1|x)$，即通过概率。例如，如果学习时间 $x=3$ 小时，模型计算 $z = \beta_0 + \beta_1 \times 3$，然后通过sigmoid函数得到概率。假设 $\beta_0 = -5$ 和 $\beta_1 = 2$，则 $z = -5 + 2 \times 3 = 1$，$P(y=1|x) = 1/(1+e^{-1}) \approx 0.73$，表示通过概率为73%。

**关联性**：正例和负例的定义决定了模型输出的解释方式。概率估计是逻辑回归的关键输出，直接用于后续的决策边界划分。

### 3. 逻辑回归的决策边界：从概率到分类决策

决策边界是用于分类的阈值界面，它将特征空间划分为正例和负例区域。在逻辑回归中，决策边界由概率阈值（通常默认为0.5）决定：当 $P(y=1|x) > 0.5$ 时，预测为正例；否则预测为负例。从数学原理看，由于 $P(y=1|x) = 0.5$ 对应 sigmoid 函数输入 $z=0$，因此决策边界方程是：
$$
z = \beta_0 + \beta_1 x_1 + \cdots + \beta_n x_n = 0
$$
这是一个线性超平面，在二维特征空间中是一条直线。

继续以考试通过为例，假设只有学习时间一个特征 $x$，模型参数为 $\beta_0 = -5$ 和 $\beta_1 = 2$。决策边界对应 $z = -5 + 2x = 0$，解得 $x = 2.5$ 小时。这意味着：
- 当学习时间 $x > 2.5$ 小时时，$P(y=1|x) > 0.5$，预测为通过（正例）。
- 当学习时间 $x < 2.5$ 小时时，$P(y=1|x) < 0.5$，预测为不通过（负例）。

决策边界可视化：在二维图中，横轴是学习时间，纵轴是通过概率，决策边界是概率0.5处的垂直线（对应 $x=2.5$）。

**关联性**：决策边界直接源于线性部分 $z=0$，将概率估计转换为分类结果。它依赖于模型参数，而这些参数通过训练数据估计，以最大化正例和负例的分类准确性。

### 4. 逻辑回归的阈值选择：平衡分类性能的灵活性

阈值选择是逻辑回归中一个实践性很强的环节，它决定了决策边界的精确位置。默认阈值0.5适用于正例和负例成本相近的场景，但在实际应用中，我们可能需要调整阈值以优化分类性能。例如，在医疗诊断中，将疾病检测为正例，降低阈值（如设为0.3）可以减少假阴性（漏诊），但可能增加假阳性（误诊）；反之，提高阈值（如设为0.7）可以减少假阳性，但增加假阴性。

阈值调整本质上是移动决策边界。从数学上看，设定阈值 $t$（0到1之间），决策规则变为：如果 $P(y=1|x) > t$，则预测为正例。由于 $P(y=1|x) = \sigma(z)$，这等价于 $z > \sigma^{-1}(t)$，其中 $\sigma^{-1}$ 是sigmoid反函数。例如，如果 $t=0.3$，对应 $z = \sigma^{-1}(0.3) \approx -0.85$，决策边界变为 $z = -0.85$，即 $\beta_0 + \beta_1 x_1 + \cdots = -0.85$。在考试例子中，如果降低阈值到0.3，决策边界从 $x=2.5$ 小时左移，使得更多学生被预测为通过。

阈值选择通常基于性能指标，如精确率（预测为正例中实际为正例的比例）和召回率（实际正例中被正确预测的比例）。通过ROC曲线或精确率-召回率曲线，我们可以选择适合问题需求的阈值。

**关联性**：阈值选择是决策边界的动态调整工具，它直接影响正例和负例的分类结果，体现了逻辑回归的灵活性。阈值的改变反映了对分类错误成本的权衡，而决策边界随之移动，展示了概率估计与分类决策的紧密耦合。

### 结论

逻辑回归通过四个核心知识点有机连接，形成一个完整的分类框架。首先，它继承线性回归的线性模型，但通过sigmoid函数转换为概率估计，从而处理分类问题。其次，正例和负例的定义赋予概率以实际意义，使模型输出可解释。接着，决策边界基于概率阈值将连续概率离散化为分类决策，其本质是线性超平面。最后，阈值选择允许我们根据具体需求调整决策边界，以平衡分类性能。这些知识点环环相扣：线性模型提供基础，概率估计桥连连续与离散，决策边界实现分类，而阈值选择优化应用。通过考试通过的例子，我们看到数学原理简单明了——从线性方程到sigmoid变换，再到阈值比较，逻辑回归以优雅的方式将回归与分类统一起来，成为机器学习中不可或缺的工具。
